# Provenance: the query bridge

Ported on 2026-10-09 from myapps (`grmkris/myapps`), commit `27416c98e863abd8d474db715f0af2e69b684faa`, package
`packages/query/src` (`@myapps/query`). The pattern is myapps ADR 0013 (`docs/adr/0013-ui-data-layer.md`) and
`docs/agents/ui-data.md`: an Effect HttpApi contract per app, TanStack Query owns server data.

| goblin file       | myapps source                           | What changed                                                                                                                                                                                                                                                                                                                                                                                        |
| :---------------- | :-------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api-query.ts`    | `api-query.ts`                          | `headers` may be a function of the outgoing request and its operation, so each request gets a fresh `x-goblin-request` id and CSRF only on writes; `CurrentOperation` and `withOperation` name the operation a write runs as (`x-goblin-operation`). `isTransient` left out until something uses it.                                                                                                |
| `app-error.ts`    | `app-error.ts`                          | Classifies goblin's typed `AppError` classes through the contract (`ERROR_COPY`, `statusOf`), not myapps' code table; `ERROR_KINDS` pins goblin's codes. Views carry `ref`: the reference the agent stamped, else the response's `x-goblin-ref`, else the request id the client sent. `messageOf` ends with "· ref 7f3a9c12". 402 reads as `plan_limit`; a `subscribe` link becomes `recoveryHref`. |
| `testing.ts`      | `testing.ts`                            | `fakeHttpApi` as is. `testQueryClient` counts sign-in callbacks in `signIns` instead of a `vi.fn` spy, so no source module imports vitest. `fakeRoutes` and `installFakeFetch` left out.                                                                                                                                                                                                            |
| `route-error.tsx` | `route-error.ts`, `router-defaults.tsx` | `useRouteErrorRetry` as is. myapps' `makeRouterDefaults` renders `@myapps/ui` views goblin does not have; `RouteError` is a lean equivalent on goblin's `Empty` and `Button`, with an `onCrash` hook for client error reports; `ReportedRouteError` (the router's default) reports defects to `/api/client-errors`.                                                                                 |

Not ported yet: `query-boundary.tsx` (`QueryBoundary`; it fits goblin's `Alert` and `Button` as is, and comes with the
first panel that needs it), `better-auth.ts` and `oauth.ts` (goblin keeps its own auth client).
